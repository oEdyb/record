# Editor UX laws — September 8, 2026

## Brief and acceptance checks

Klippt serves creators editing screen and camera recordings. The job is to find the right control,
make an intentional edit, review the result and save a usable export. Keep the existing graphite
chrome, Geist labels, Geist Mono numbers, steel-blue editing selection and dominant video preview.
Reuse the project inspector, Radix controls and modal system. No external UI kit or dependency.

Acceptance checks:

1. Find each inspector section without memorizing icons, including at the supported narrow Mac window.
2. Enter an exact setting, recover from invalid input and cancel a draft without changing the edit.
3. Review an automatic effect by keyboard, keep focus after saving and see a truthful result.
4. Find presets immediately and reveal detailed automatic tuning only when wanted.
5. See project save state beside its name; get keyboard help for toolbar icons.
6. Export completion clearly identifies the saved file and offers reveal/close; failure keeps choices for retry.
7. Keep the preview, controls and timeline usable at standard and narrow sizes, with visible focus and reduced motion.

## All entries in the supplied reference

The skill has 20 numbered entries: 16/17 repeat Postel, and 8 is the distance component of Fitts.
These are context-dependent principles. The table records concrete applications, including existing
behavior that should remain. It does not claim a measured reduction in task time or improved memory.

## Primary references

- [W3C labels and instructions](https://www.w3.org/WAI/WCAG22/Understanding/labels-or-instructions.html): visible meaning as well as accessible names.
- [Radix Toggle Group](https://www.radix-ui.com/primitives/docs/components/toggle-group): installed library owns roving focus and selection semantics; selected items use fill/text without an inset edge. Compact toolbar overflow uses the existing Radix menu.
- [Radix Tooltip](https://www.radix-ui.com/primitives/docs/components/tooltip): focus/hover help through the installed primitive.
- [React controlled inputs](https://react.dev/reference/react-dom/components/input): local drafts and explicit controlled values; installed React 18.3.1 source checked.
- [Radix Slider](https://www.radix-ui.com/primitives/docs/components/slider): retain separate value-change and commit events; installed source checked.
- [React DOM refs](https://react.dev/learn/manipulating-the-dom-with-refs) and [W3C keyboard interface](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/): restore focus after removing its former target.
- [W3C button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/) and [meter guidance](https://www.w3.org/WAI/ARIA/apg/patterns/meter/): expose toggle selection; use progressbar semantics for task progress.
